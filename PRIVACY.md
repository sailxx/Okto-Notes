# Политика конфиденциальности Okto Notes / Privacy Policy

Действует с 25.10.2026. Okto Notes — Android-приложение для заметок и дневника. Разработчик: sailxx (https://github.com/sailxx).

## Русский

**Что хранится.** Заметки и записи дневника — в JSON во внутренней памяти приложения на вашем устройстве. Другим приложениям они недоступны.

**Синхронизация (по желанию).** Если вы включили связь с Okto и вошли через Google, заметки (не дневник) синхронизируются через Google Firebase / Cloud Firestore (`users/{ваш uid}/notes`) по REST-запросам. Доступ к этим данным только у вас. Без включённой синхронизации приложение в сеть не обращается.

**Разрешения.** Только «Интернет» — для этой синхронизации.

**Чего нет.** Рекламы, аналитики, трекеров, передачи данных третьим лицам. Разработчик не читает ваши записи.

**Удаление.** Удалите записи в приложении или само приложение — локальные данные будут стёрты. Для удаления облачных данных откройте Issue в репозитории.

**Дети.** Не предназначено для детей до 13 лет.

Актуальная версия: https://github.com/sailxx/Okto-Notes/blob/main/PRIVACY.md

## English

**What is stored.** Notes and diary entries are kept as JSON in the app's internal storage on your device, inaccessible to other apps.

**Optional sync.** If you enable the link with Okto and sign in with Google, notes (not the diary) are synced through Google Firebase / Cloud Firestore (`users/{your uid}/notes`) over REST. Only you can access them. With sync off, the app makes no network requests.

**Permissions.** Internet only, for that sync.

**What we don't do.** No ads, analytics, trackers or sharing with third parties. The developer does not read your entries.

**Deletion.** Delete entries or uninstall the app to erase local data. To remove cloud data, open an Issue in the repository.

**Children.** Not intended for children under 13.
